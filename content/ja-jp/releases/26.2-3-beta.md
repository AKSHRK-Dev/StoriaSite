### 新機能

- **Storia Worker が Cluster のサーバー**になりました。ワーカーを足すだけで、処理できるプレイヤーを増やせます。[[worker]]
- **新しいワーカーにワールドのコピーは不要**：初回起動時に、ワールドの設定（level.dat、生成設定、データパック）を Relay から取り寄せます。

### 改善

- Storia Relay は Cluster のまとめ役に専念します。
- 暗号化した通信の最初に、お互いを確かめる手順（ハンドシェイク）を加えました。

### 削除

- 地形だけを別のマシンで計算する機能（`storia.yml` の `offload.*`、`-Dstoria.worker=true`、`/storia offload`）を削除しました。
  古い `offload:` の設定は無視されます。古い設定のサーバーが Relay につなぐと、その旨のメッセージで断られます。
  コードは GitHub の `archive/terrain-offload` ブランチに残しています。
