**Storia Relay** は [[cluster|Storia Cluster]] のまとめ役です。

- **ワールドを保管します**。普通の Minecraft のワールドフォルダ（Anvil 形式のリージョンファイル）と、プレイヤーデータ・
  進捗・統計、地図やスコアボードなどの共有データです。
- **ワールドを割り当てます**。セル（32 × 32 チャンク）ごとに、同時に動かせるのは 1 台の [[worker]] だけです。
- **プレイヤーを配置します**。近づいたプレイヤーは同じワーカーへ、忙しいワーカーの仕事は空いているワーカーへ移し、
  境目にある回路のセルは一緒にしておきます。
- **Storia Proxy に伝えます**。プレイヤーを別のワーカーへ移すタイミングです。

Relay に必要なのは **Java 21 以上**とワールド分のディスクだけで、Minecraft サーバーは要りません。ワールドを
動かす重い仕事はワーカーが行います。

## 導入

1. `storia-relay-{{VERSION}}.zip` をダウンロードして展開します。
2. 一度起動します。`relay.properties` を作って終了します。

    ```bash
    ./start-relay.sh        # Windows は start-relay.bat
    ```

3. 合言葉（[[security]] を参照）を設定し、ワールドを `cluster-world/` に置きます。

    ```properties
    bind=0.0.0.0
    port=25590
    secret=長い合言葉を決める
    compress=true
    cluster-world=cluster-world
    ```

4. もう一度起動します。これ以降、**`cluster-world/` に書き込むのは Relay だけ**です。バックアップはここから取ります。

## コンソール

| コマンド | 内容 |
| --- | --- |
| `status` | ワーカー、各ワーカーが動かしているセル、プレイヤー、移動、回路のつながり、読み書きの数。 |
| `stop` | Relay を止めます。 |

## Relay が止まったとき

ワーカーは動き続けます。送れない書き込みは順番どおりワーカーのディスクの `cluster-spool/` に貯め、Relay が戻ったら
送ります（ワーカーを再起動した後でも）。ワーカーはつながり直したときに、自分の場所をもう一度確保します。Relay が
戻るまで、新しいプレイヤーは入れず、移動も起きません。

## 設定

| キー | 初期値 | 内容 |
| --- | --- | --- |
| `bind` | `0.0.0.0` | 待ち受けるアドレス。 |
| `port` | `25590` | ワーカーと Storia Proxy 用のポート。 |
| `secret` | （空） | 共通の合言葉。8 文字以上。必須。 |
| `compress` | `true` | 暗号化の前にメッセージを圧縮します。 |
| `cluster-world` | `cluster-world` | 共有するワールドのフォルダ。 |
