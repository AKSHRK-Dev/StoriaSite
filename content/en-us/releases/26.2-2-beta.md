### New

- **Storia Cluster (beta)**: several Storia servers share one world. [[cluster]]
  - Storia Relay stores the world and decides which server runs which part.
  - Players who come close are put on the same server before they could see each other's chunks.
  - Players move between servers through Storia Proxy **without a loading screen**, keeping their inventory,
    advancements and statistics.
  - Contraptions on a border are found and always run on one server.
  - Time, weather, game rules, the scoreboard and maps are shared.
  - If the relay is briefly away, writes are kept on disk and sent later.
  - `/stop` moves players to the other servers before stopping.
- **Storia Proxy** switches players to another server when the relay says so, keeping the same entity id.

### Fixed

- A player is never moved twice while Storia Proxy is still switching them.

### Removed

- The border pushback and its "Another Storia server runs the area ahead" message. Areas are merged early, so they
  are no longer needed.

### Other

- Moves between servers were checked with a real Minecraft 26.2 client.
- 26.2 and 26.2-1-beta do not include Storia Cluster.
