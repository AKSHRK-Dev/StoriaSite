### New

- **RAM world**: the world is copied to RAM on start and written to disk in the background. If the process dies,
  the next start recovers from the copy in RAM. [[ram-world]]
- **Chunk pregeneration**: `/storia pregen` generates chunks before anyone plays there. [[pregeneration]]
- **Faster world generation**: faster noise sampling and block counting, with bit-for-bit the same results as vanilla.
- **Per-player budget**: shares tick time and memory fairly while the server is busy. [[player-budget]]
- **Faster entity pushing**: crowded mobs cost less, with the same results.
- **Terrain offload** (Storia Worker and Storia Relay): the terrain noise of new chunks can be computed on other
  machines over an encrypted link. Replaced by Storia Cluster in 26.2-3-beta.
- **Storia Proxy**: a Velocity fork with 50 placeholders, MOTD, tab list and message settings. [[proxy]]
- The `/storia` command for status, syncing and more. [[commands]]

### Other

- Renamed from Stolia to **Storia**.
- Version numbers follow Minecraft (26.2, then 26.2-2, 26.2-3, ...).
