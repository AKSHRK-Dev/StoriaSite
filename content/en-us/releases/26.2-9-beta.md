### New

- **Linear region format**: regions can be stored as one Zstandard file each (`r.X.Z.linear`). Set
  `region-format.type: linear` in `storia.yml`. [[linear]]
  - 12 overworld regions (46.1 MB) became 25.5 MB at compression level 1 and 21.4 MB at level 6. The End shrinks more.
  - Existing worlds just work: a region is read from its `.mca` the first time it is used and written as `.linear` from
    then on (the `.mca` is left in place).
  - Files are interchangeable with the [Linear tools](https://github.com/xymb-endcrystalme/LinearRegionFileFormatTools),
    checked with the tools' own reader.
  - Works with the RAM world (smaller files, less RAM).
  - An unreadable `.linear` file is never overwritten, and Storia refuses to start on `anvil` when the world has
    `.linear` files, so it never runs on outdated `.mca` copies.
