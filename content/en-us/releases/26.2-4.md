### New

- **Plugin API (shared data)**: plugins can share data and messages across every worker in a cluster. [[plugin-api]]
  - A key-value store per plugin (`get`, `set`, `delete`, `keys`).
  - `compareAndSet`, which only one worker can win (locks), and `increment`, which never loses a count
    (balances, counters).
  - Change notifications, and messages that reach every worker (`publish`, `subscribe`).
  - Everything is asynchronous and never blocks the game.
  - **The same API works on a single server**, so plugins need only one code path.
  - `storia-api-26.2-4.jar` is published for plugin developers.
  - Test: 200 increments from each of two workers at the same moment give exactly 400.

### Fixed

- Two workers started with the same `cluster.node-name` no longer knock each other off the cluster. The second one
  is refused with a message asking for a unique name.
