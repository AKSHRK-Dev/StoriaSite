### New

- **Storia Worker is now a cluster server.** Add workers to handle more players. [[worker]]
- **New workers need no copy of the world**: on first start they fetch the world settings (level.dat, generation
  settings, data packs) from the relay.

### Improved

- Storia Relay is now only the cluster's coordinator.
- Encrypted connections start with a handshake in which both sides identify themselves.

### Removed

- Terrain-only offload (`offload.*` in `storia.yml`, `-Dstoria.worker=true`, `/storia offload`). An old `offload:`
  section is ignored, and an old server that asks the relay for offload is refused with a message. The code is
  kept in the `archive/terrain-offload` branch on GitHub.
